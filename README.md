# My personal site

Plain HTML + CSS. There's no build step and nothing to install.

## Edit it
- **Experiences:** `experiences.js`. Each block becomes one item in the list.
- **Things I like:** `likes.js`, which works the same way.
- **Name and bio:** `index.html`.
- **Styling:** `style.css`.
- **Preview:** double-click `index.html` to open it in your browser.

## Put it online for free (GitHub Pages)
1. Make a free account at https://github.com.
2. Create a new **public** repository named exactly `<your-username>.github.io`.
3. Upload these files: on the repo page, click **Add file → Upload files** and drag them in.
   You can also push them with git.
4. Wait about a minute, then visit `https://<your-username>.github.io`.

To update the site later, edit the files and upload or push them again.

**Optional custom domain** (e.g. `jasonau.com`, about €10/yr): buy one from a registrar, then add it under
repo **Settings → Pages → Custom domain** and follow GitHub's DNS instructions.

Netlify Drop (https://app.netlify.com/drop) and Cloudflare Pages are also free.
With Netlify Drop you drag the folder onto the page and it's live.
